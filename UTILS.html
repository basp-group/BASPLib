UTILITIES


Some of the building blocks behind the algorithms

"The most useful tools in the galaxy."

BASPLib offers a suite of utility codes for simulations in Matlab and Python. The suite features two standalone libraries. The first is dedicated to the implementation of the SII measurement operator. It also provides scripts for simulating a wide-variety of Fourier sampling patterns from the antenna configurations of modern telescopes. The second is dedicated to the implementation of the SARA wavelet dictionary, which underpins the regularisation module of the SARA family.
