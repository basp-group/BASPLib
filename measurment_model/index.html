PHI & MROP

Measurement model

"When the galaxy map to the observation."

BASPLib offers a suite of utility codes for simulations in Matlab and Python. The suite features two standalone libraries. The first is dedicated to the implementation of the RI measurement operator (PHI). It also provides scripts for simulating a wide-variety of Fourier sampling patterns from the antenna configurations of modern telescopes. The second is dedicated to the implementation of Modulated Rank-One Projection (MROP), a library for data dimensionality reduction scheme.
